# Delivery plan

## Version 1 — production MVP

- Public URL trace
- DNS A, AAAA, CNAME, NS and CAA observations
- Manual redirect timeline
- HTTP timing and selected response metadata
- Cache and security-header analysis
- HTML dependency inventory
- Evidence-linked deterministic findings
- Shareable 14-day reports
- JSON export
- Anonymous abuse controls
- Responsive visual interface

## Version 1.1

- Compare two reports
- Scheduled monitoring
- Change notifications
- Custom retention for authenticated users

## Version 2

- Browser Rendering waterfall and screenshots
- Desktop/mobile comparison
- Regional observation modes
- Team workspaces and annotations

## Success criteria

- A normal public HTTPS URL produces a report in under 15 seconds.
- Every finding links to captured evidence.
- Private and reserved targets are rejected at every redirect.
- A stored report can be loaded without rerunning the scan.
- The interface remains usable at 360 px viewport width.
